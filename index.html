🔧 Google API Setup Guide

  1. Go to Google Cloud Console
  2. Create a new project (or select existing)
  3. Go to APIs & Services → Library
  4. Enable Google Sheets API
  5. Go to APIs & Services → Credentials
  6. Click Create Credentials → OAuth client ID
  7. Choose Web application
  8. Add http://localhost:8080 to Authorized JavaScript origins
  9. Copy the Client ID and paste it above
Important: You also need to configure the OAuth consent screen. Choose "External" and add your email as a test user.
